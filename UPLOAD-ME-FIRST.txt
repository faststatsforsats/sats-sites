STEP 17: THE STATS SITE. HOW TO GET THESE FILES INTO GITHUB
============================================================

This folder has the same layout as the sats-sites repository. 81 files: step 17 (the Stats site), the
brand work (your coins and wordmarks in the header and footer of all three sites, favicons, social cards,
the navy and orange palette), and the new chart look, with the seven charts already redrawn from the
October 1 data (charts/*.png and *.svg; the Daily Build keeps redrawing them every morning). Nothing in
data/ except data/README.md. This zip replaces the earlier ones; upload this one only.

PART 1: DRAG THE FOLDERS (36 files)
-----------------------------------
1. In Chrome, open https://github.com/faststatsforsats/sats-sites
2. Click the green "Code" button's neighbor "Add file", then "Upload files".
3. In File Explorer, open this unzipped folder (sats-sites-step17).
   Press Ctrl+A to select everything in it: CLAUDE.md, content, data, lib, scripts, shared, sites.
   (This text file can come along; it is harmless, or leave it out.)
4. Drag the selection onto the dotted upload box in Chrome.
   Dragging folders keeps the folder paths. Do NOT use the "choose your files" link; that
   flattens everything into the root, which is what went wrong in step 16.
5. Wait for the list under the box to finish. It should show 80 files with paths like
   shared/templates/amount.html, shared/static/brand/stats-coin.png, and charts/sats-per-dollar.png.
   nostr.json will be missing from the list; GitHub skips folders whose name starts with a dot.
   Part 2 handles it.
6. Commit message: Step 17: the Stats site, with the logos, brand colors, and the new charts
   Leave "Commit directly to the main branch" selected. Click "Commit changes".

PART 2: THE ONE DOT-FOLDER FILE
-------------------------------
1. Back on the repository page, "Add file", then "Create new file".
2. In the file name box type exactly:   sites/stats/static/.well-known/nostr.json
   (each slash turns into a folder as you type)
3. Paste this as the contents:

{
  "names": {
    "_": "5d1e85165c869fefc1fb0e62f200ad66bbe8377ca54ce6fec1c2034e67ca23b0",
    "stats": "5d1e85165c869fefc1fb0e62f200ad66bbe8377ca54ce6fec1c2034e67ca23b0"
  }
}

4. Commit message: Add NIP-05 nostr.json     Commit directly to main.
